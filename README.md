# channel-sale-bot

Исходники бота для управления подписками на закрытый канал в Telegram и MAX. В репозитории можно посмотреть, как устроены меню администратора и хранение подписок в SQLite.

- [База данных](database.py) хранит пользователей, подписки, платежи, рефералов и промокоды. [В конфигурации](config.py) заданы три тарифа.
- [Админка Telegram](handlers/admin.py) показывает статистику, управляет промокодами, шагами онбординга и рассылками. Для MAX есть [ручная выдача доступа](max/handlers.py), [клиент API](max/api.py) и [отзыв доступа по сроку](max/bot.py).
- Обработчики старта и выбора тарифа в Telegram оставлены заглушками. Интеграция с [ЮKassa](services/yookassa.py) оставлена заглушкой для обеих платформ. [Обработка платежей](handlers/payment.py) и [выдача или отзыв доступа](services/subscription.py) в Telegram также оставлены заглушками.

## Запуск

Точки входа Telegram и MAX находятся в [bot.py](bot.py) и [max/bot.py](max/bot.py). Зависимости перечислены в [requirements.txt](requirements.txt), переменные окружения в [.env.example](.env.example). В тестовом контуре команды `python bot.py` и `python -m max.bot` запускают соответствующие точки входа. Для сквозной продажи подписок нужны реализации платежей и Telegram-доступа.
